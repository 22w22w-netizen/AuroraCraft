说明

            
    
              
  • Fabric / Quilt：拉取官方 profile JSON（含 mainClass 与库列表），下载库后直接生成版本。
    • 
              
  • Forge / NeoForge：下载官方安装器，调用 Java 执行 --installClient 完成安装。
    • 
              
  • 安装完成后，新版本会出现在「版本库 → 已安装」与启动页版本列表中。
    • 
              
  • 加载器版本需要与基础游戏版本兼容，建议选择最新稳定版。
